Level 0 · The Wall

Parallel on local hits a wall

Problem 1 — It's tethered
  • ▸Close the laptop and everything stops.
  • ▸No progress while you're away.
Problem 2 — Infra eats your day
  • ▸Each feature needs BEs, FEs, env vars running locally.
  • ▸You maintain infrastructure instead of shipping.

To move fast: use existing infrastructure — don't rebuild it.

Local doesn't scale.

Level 1

Into the cloud

Cloud agents and ephemeral environments — infra already there.

Level 1 · Cloud

Move the work to where the infra already is

  • ▸Use Gemini from Cursor Cloud Agents, infra ready out of the box.
  • ▸Each change runs in an isolated container.
  • ▸Kick off work from your phone — laptop optional.
  • ▸Stop maintaining; start shipping.
Level 1 · Cloud · Verification

Real verification needs ephemeral environments

  • ▸Gets you closer to production.
  • ▸Enables real testing, not mocks on a laptop.
  • ▸Firebase Preview environments per branch.
  • ▸Every agent's solution gets its own URL to inspect.
  • ▸Not right? Re-run the loop — as many times as you want.

Level 2 · An agent takes the tickets

Hand the agent the ticket

  • ▸An agent picks up a ticket and fixes it end-to-end — autonomously.
  • ▸It runs async and unsupervised — no babysitting each step.
  • ▸You shift from doing the work to reviewing the outcome.
Level 2 · An agent takes the tickets

One option: Google Jules

Async by design — give it a task, it takes care of it end to end.

Level 2 · An agent takes the tickets

Schedule it, point it at Linear

  • ▸Connect it to Linear — pull tickets straight from your tracker.
  • ▸Runs unattended in a cloud VM — opens the PR when done.

Level 3

Auto review

The last human gate gets automated.

Level 3 · Auto review

Now everyone's bottleneck is review

  • ▸Ten agents, ten PRs — humans can't keep up.
  • ▸Delegate the first pass to an AI reviewer.
  • ▸It returns a confidence score — safe to merge or not?
  • ▸Easier call for everyone on the team.
Level 3 · Auto review

One reviewer agent per pull request

name: AI Code Review
on: [pull_request]
jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Gemini review
        uses: google-gemini/gemini-cli-action@v1
        with:
          prompt: "Review this PR. Return a
            merge-confidence score 0-100."
      - name: Gate on confidence
        run: ./scripts/require-confidence.sh --min 80
