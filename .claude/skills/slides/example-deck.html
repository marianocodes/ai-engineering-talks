Why this matters

The shift from prompts to systems

  • ▸Models are one component, not the product.
  • ▸Reliability comes from retries, evals, and guardrails — not bigger models.
  • ▸Context engineering beats prompt engineering.
  • ▸Tool use turns LLMs into agents — and agents into infrastructure.
Pattern

A tool call, in one screen

from anthropic import Anthropic

client = Anthropic()

response = client.messages.create(
    model="claude-opus-4-7",
    max_tokens=1024,
    tools=[{
        "name": "get_weather",
        "description": "Get current weather for a city",
        "input_schema": {
            "type": "object",
            "properties": {"city": {"type": "string"}},
            "required": ["city"],
        },
    }],
    messages=[{"role": "user", "content": "What's the weather in Buenos Aires?"}],
)

The model decides when to call. You decide what it can call.

Mental model

Prompt engineering vs. AI engineering

Prompt engineering
  • ▸One string, one model, one shot.
  • ▸Tweak wording until output looks right.
  • ▸Vibes-based evaluation.
AI engineering
  • ▸Pipelines, retries, caching, tools.
  • ▸Versioned prompts, regression evals.
  • ▸Observability over guesswork.
